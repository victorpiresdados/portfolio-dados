# Clínica Médica: código SQL

Estrutura do banco e views em SQL Server usadas no dashboard em Power BI.

| Arquivo | Conteúdo |
| --- | --- |
| `01_criar_banco_e_tabelas.sql` | Banco, tabelas, chaves primárias e estrangeiras |
| `02_modelo_power_bi.sql` | Modelo dimensional: 3 fatos, 4 dimensões e relacionamentos |
| `03_views_analiticas.sql` | Views de consulta e indicadores |
| `04_validar_carga.sql` | Conferência da quantidade de linhas por tabela |

Os scripts de carga não estão publicados porque contêm registros simulados de pessoas, com telefones e e-mails fictícios. Os dados do projeto são fictícios.
